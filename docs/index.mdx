This document specifies how the Mongolian script is encoded and shaped. It treats the writing systems in which the script is written—Hudum, Todo, Sibe, and Manchu, together with their Ali Gali extensions—and for each of them fixes the characters that represent its written units and the layered, sequential steps by which a sequence of characters is shaped into the written units it is rendered with. Those steps are aligned with the Unicode Standard and with China’s national standard GB/T 25914—2023: they take the variant-selection conditions of those standards, which are stated flatly and leave the order of application open, and reorganize them into the order in which a text shaping engine executes them.

The repository maintains more than the text of the rules. The rule data are kept as TypeScript files in `data/`—the source of truth for the characters, written units, variants, aliases, ligatures, and particles of every writing system. `mongfontbuilder`, the Python library, reads those data and generates the OpenType Layout rules of a font, so that a minimal glyph set becomes a complete font; it is also the reference implementation of this document. The Glyphs templates in `templates/` carry its output into the type designer’s hands, and the test suite in `mongfontbuilder/tests/` shapes the test cases of the national standards with [HarfBuzz](https://harfbuzz.github.io/) and checks the result against what those standards expect.
