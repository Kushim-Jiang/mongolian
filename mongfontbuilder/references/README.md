# References

Nothing reads these; they are kept as the material the cases and the names above came from.

- `eac-hudum.json`, `eac-todo.json`, `eac-sibe.json`, `eac-manchu.json` — the EAC test suites as they are published, one file per writing system, of which `eac-hudum.tsv` is the one the suite reads. The documentation of the model quotes `eac-hudum.json` as the test data of the national standard. The rule test pages they were taken from are offline, and the Internet Archive holds none of them. The A-prefixed Ali Gali rule words of the published suite are not carried into `eac-hudum.tsv`; the Ali Gali cases the suite runs are the ones of `core-hudum-ali-gali.tsv`.
  - eac-hudum.json: `xunifont_rulewords_mon.js`, of the Hudum rule test page
  - eac-todo.json: `xunifont_rulewords_todo.js`, of the Todo rule test page
  - eac-sibe.json: `xunifont_rulewords_sibe.js`, of the Sibe rule test page
  - eac-manchu.json: `xunifont_rulewords_man.js`, of the Manchu rule test page
- `menksoft.txt` — the private-use code points of the Menksoft fonts, read against the glyph names that stand for them.
