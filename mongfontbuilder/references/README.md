# References

Nothing reads these; they are kept as the material the cases and the names above came from.

- `eac-hudum.json`, `eac-todo.json`, `eac-sibe.json`, `eac-manchu.json` — the EAC test suites as they are published, one file per writing system, of which `eac-hudum.tsv` is the one the suite reads. The documentation of the model quotes `eac-hudum.json` as the test data of the national standard.
  - eac-hudum.json: [xunifont_rulewords_mon.js](http://rule.xueruhai.com/ruletest/xunifont_rulewords_mon.js) of [Hudum](http://rule.xueruhai.com/ruletest-mon.php)
  - eac-todo.json: [xunifont_rulewords_todo.js](http://rule.xueruhai.com/ruletest/xunifont_rulewords_todo.js) of [Todo](http://rule.xueruhai.com/ruletest-todo.php)
  - eac-sibe.json: [xunifont_rulewords_sibe.js](http://rule.xueruhai.com/ruletest/xunifont_rulewords_sibe.js) of [Sibe](http://rule.xueruhai.com/ruletest-sibe.php)
  - eac-manchu.json: [xunifont_rulewords_man.js](http://rule.xueruhai.com/ruletest/xunifont_rulewords_man.js) of [Manchu](http://rule.xueruhai.com/ruletest-man.php)
- `menksoft.txt` — the private-use code points of the Menksoft fonts, read against the glyph names that stand for them.
